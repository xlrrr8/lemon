# Orange. 🍊

An elegant, minimalist, and ultra-smooth chess experience built with React, Vite, and TypeScript.

## 🌟 Features

- **Ultra-Smooth UX**: Custom piece dragging using native pointer events for highly responsive transitions.
- **Dynamic Animations**: Fluid, dynamic animations for piece movements.
- **Skeuomorphic & Glassmorphism Design**: Beautiful modern visual theme featuring vibrant colors and smooth gradients.
- **Interactive Move Review**: Browse past moves with custom classification tables (Brilliant, Great, Book, Best, etc.).
- **Immersive Sounds**: Sound effects for move, capture, puzzle errors, and navigation.

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Shadcn-ui
- **State/Routing**: React Router DOM + TanStack Query

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/xlrrr8/lemon.git
   cd lemon
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
